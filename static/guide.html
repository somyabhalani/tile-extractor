User Guide & Features

How to Use

1

Upload Catalogue

Drag and drop your PDF catalogue into the upload zone or click to select the file. For best results, use high-resolution PDF files.

2

Automatic Extraction

The system will automatically scan each page and extract every tile image into a clean, lossless format. You can monitor the progress bar in real-time.

3

Scan Text Data

Click the "Scan Text" button on any page. Our Vision AI will identify products and match them to the extracted tiles using a visual flow heuristic.

4

Inspect & Download

Click any tile to see its technical metadata (size, path, page). You can download individual tiles or the entire processed package as a ZIP.

Key Features

Lossless Quality

Extracts images directly from the PDF data structures to ensure zero quality loss compared to the original.

Vision AI Match

Uses advanced NVIDIA Vision AI to read spec blocks and pair text with specific tile images automatically.

Metadata Insight

Provides deep technical insights into every image, including physical dimensions, memory size, and page origin.

Instant ZIP Export

Package thousands of extracted tiles into a single organized ZIP file with one click.
